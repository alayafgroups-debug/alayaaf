## الخطوة 3️⃣: اختبر الدخول

### يوجد 3 طرق للدخول:

#### **الطريقة 1: بالبريد الإلكتروني**
```
رابط: /login

البيانات:
  البريد: zain@company.com
  كلمة المرور: 12345
```

#### **الطريقة 2: برقم الموظف (جديد)** ⭐
```
رابط: /employee/login

اختر: "رقم الموظف"

البيانات:
  رقم الموظف: EMP-001
  كلمة المرور: 12345
```

#### **الطريقة 3: من صفحة التسجيل**
```
رابط: /admin/register-employee

سجل الموظف بنفس البيانات
```
